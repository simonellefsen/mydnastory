# Decisions

Durable product, scientific, privacy, architecture, and workflow decisions belong here.

Each decision record contains:

- context;
- decision;
- consequences;
- alternatives considered;
- verification or implementation status;
- links to affected concepts, code, and source notes.

Do not rewrite the original decision when implementation changes. Append an outcome or create a superseding record.
